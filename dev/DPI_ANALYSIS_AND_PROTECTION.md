# 🔍 Анализ DPI угроз и защита от них

## ⚠️ **Что может обнаружить DPI:**

### 1️⃣ **Анализ TLS трафика:**
```
🔍 DPI может анализировать:
- TLS Handshake паттерны
- Размеры пакетов и их последовательность  
- Временные интервалы между пакетами
- Энтропию зашифрованных данных
- SNI (Server Name Indication) в открытом виде
- JA3/JA4 fingerprints клиентов
```

### 2️⃣ **Статистический анализ:**
```
📊 Подозрительные паттерны:
- Постоянный объем трафика (VPN туннель)
- Нетипичные размеры пакетов
- Отсутствие HTTP/2 мультиплексирования
- Аномальные RTT (Round Trip Time)
- Слишком равномерное распределение данных
```

### 3️⃣ **Поведенческий анализ:**
```
🎯 Подозрительное поведение:
- Долгоживущие соединения (часы/дни)
- Отсутствие типичных веб-паттернов
- Нет загрузки изображений/CSS/JS
- Постоянная активность без пауз
- Нетипичные User-Agent строки
```

## 🛡️ **Наша текущая защита от DPI:**

### ✅ **REALITY протокол:**
```json
"realitySettings": {
  "dest": "www.cloudflare.com:443",
  "serverNames": ["www.cloudflare.com"],
  "show": false,
  "fingerprint": "random"
}
```

**Защищает от:**
- ✅ SNI анализа (имитирует Cloudflare)
- ✅ TLS fingerprinting (случайные отпечатки)
- ✅ Сертификатного анализа (настоящие сертификаты Cloudflare)
- ✅ Поведенческого анализа (перенаправляет реальный трафик)

### ✅ **XTLS-RPRX-Vision:**
```
"flow": "xtls-rprx-vision"
```

**Защищает от:**
- ✅ Энтропийного анализа (смешивает с реальным TLS)
- ✅ Паттерн-анализа (имитирует обычный HTTPS)
- ✅ Статистического анализа (переменные размеры пакетов)

### ✅ **Маскировка портов:**
```
Открытые порты: 80,443,2052,2053,2082,2083,2086,2087,2095,2096,8080,8443
Точно как у Cloudflare CDN
```

**Защищает от:**
- ✅ Сканирования портов
- ✅ Инфраструктурного анализа
- ✅ Профилирования сервера
