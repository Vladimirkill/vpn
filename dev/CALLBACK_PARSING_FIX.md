# 🔧 Исправление парсинга callback данных

## ✅ **Критическая проблема решена!**

### 🚨 **Найденная проблема:**
Админские кнопки не работали из-за неправильного парсинга callback данных для пользователей с подчеркиваниями в имени.

**Пример проблемы:**
```
Callback: admin_apply_limits_user_5406831921_4_6

❌ Неправильный парсинг:
parts = data.split("_")
client_name = parts[3]  # "user"
max_connections = int(parts[4])  # 5406831921 (!)
max_devices = int(parts[5])  # 4

Результат: ❌ Пользователь user не найден
```

### 🔍 **Причина:**
Имена пользователей формируются как `user_5406831921`, содержат подчеркивания. При разделении по `_` имя пользователя разбивалось неправильно.

---

## 🛠️ **Выполненные исправления:**

### **1️⃣ Исправлен парсинг для `admin_apply_limits_`:**

#### ❌ **Было:**
```python
parts = data.split("_")
client_name = parts[3]
max_connections = int(parts[4])
max_devices = int(parts[5])
```

#### ✅ **Стало:**
```python
# Убираем префикс "admin_apply_limits_"
remaining = data.replace("admin_apply_limits_", "")
# Разделяем по последним двум подчеркиваниям (лимиты всегда в конце)
parts = remaining.rsplit("_", 2)
client_name = parts[0]
max_connections = int(parts[1])
max_devices = int(parts[2])
```

### **2️⃣ Исправлен парсинг для кнопок ➖/➕:**

#### ❌ **Было:**
```python
parts = data.split("_")
action = f"{parts[1]}_{parts[2]}"
client_name = parts[3]
current_conn = int(parts[4])
current_dev = int(parts[5])
```

#### ✅ **Стало:**
```python
# Определяем действие и убираем соответствующий префикс
if data.startswith("admin_conn_inc_"):
    action = "conn_inc"
    remaining = data.replace("admin_conn_inc_", "")
elif data.startswith("admin_conn_dec_"):
    action = "conn_dec"
    remaining = data.replace("admin_conn_dec_", "")
# ... и т.д.

# Разделяем по последним двум подчеркиваниям
parts = remaining.rsplit("_", 2)
client_name = parts[0]
current_conn = int(parts[1])
current_dev = int(parts[2])
```
