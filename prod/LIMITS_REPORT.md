## 🛠️ **Управление лимитами**

### **Увеличение лимита для клиента:**
```bash
# Редактируем файл клиента
nano xray/clients/UUID.json

# Изменяем max_connections
"max_connections": 5

# Перезагружаем Xray
systemctl reload xray
```

### **Создание клиента с кастомным лимитом:**
```python
# В generate_client.py
metadata = {
    "max_connections": 10,  # Кастомный лимит
    "created_at": datetime.now().isoformat(),
    "client_name": client_name
}
```

### **Проверка лимитов:**
```bash
# Запуск проверки
python3 check_connection_limits.py

# Мониторинг в реальном времени
python3 monitor_limits.py
```

## 📋 **Файлы системы лимитов**

1. **`monitor_limits.py`** - Основной скрипт мониторинга
2. **`check_connection_limits.py`** - Проверка текущего состояния
3. **`xray/clients/*.json`** - Конфигурации клиентов с лимитами
4. **`/etc/systemd/system/xray.service`** - Systemd конфигурация
