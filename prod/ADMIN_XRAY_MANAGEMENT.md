# 🔧 Управление Xray в админке бота

## ✅ Реализованная функциональность

В админку Telegram бота добавлен полноценный механизм управления сервером Xray.

### 🎯 Новые возможности:

#### 1. **📊 Статус Xray**
- Проверка активности службы (🟢 Активен / 🔴 Неактивен)
- Отображение PID процесса
- Время запуска службы
- Автоматическая диагностика проблем

#### 2. **🔄 Перезапуск Xray**
- Полный перезапуск службы systemctl
- Автоматическая проверка успешности запуска
- Уведомления о статусе операции
- Безопасный таймаут (30 секунд)

#### 3. **🔧 Перезагрузка конфигурации**
- Использует оптимизированную функцию `reload_xray_config()`
- Сначала пытается `systemctl reload` (быстро)
- При неудаче делает `systemctl restart` (надежно)
- Автоматическое применение изменений

#### 4. **📋 Просмотр логов**
- Последние 20 записей из журнала systemd
- Автоматическое обрезание длинных логов
- Удобный формат отображения
- Быстрая диагностика проблем

#### 5. **🧹 Очистка просроченных ключей**
- Автоматическое удаление истекших ключей
- Интеграция с системой пулов ключей
- Отчет о количестве удаленных ключей
- Немедленное применение изменений

## 🎮 Как использовать:

### В Telegram боте:
1. Откройте админ панель
2. Нажмите **"🔧 Управление Xray"**
3. Выберите нужное действие:
   - **📊 Статус Xray** - проверить состояние
   - **🔄 Перезапустить Xray** - полный перезапуск
   - **🔧 Перезагрузить конфигурацию** - применить изменения
   - **📋 Логи Xray** - просмотр журнала
   - **🧹 Очистить просроченные ключи** - удалить истекшие

### Через командную строку:
```bash
# Тестирование всех функций
python3 /var/www/vpn/test_admin_xray.py

# Прямое использование функций
python3 -c "
from manage_user_limits import reload_xray_config, cleanup_expired_keys
reload_xray_config()  # Перезагрузка конфигурации
cleanup_expired_keys()  # Очистка просроченных ключей
"
```
