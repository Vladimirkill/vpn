# 🛡️ Жесткие ограничения пользователей VPN

## 📋 **Обзор системы ограничений**

Система VPN теперь имеет жесткие ограничения для контроля использования:

### 🔒 **Основные ограничения:**
- **1 ключ для одного пользователя** - каждый пользователь может иметь только один активный VPN ключ
- **Максимум 3 устройства для 1 ключа** - один ключ может использоваться максимум на 3 устройствах одновременно

### 🎯 **Цели ограничений:**
- Предотвращение злоупотреблений
- Контроль нагрузки на сервер
- Справедливое распределение ресурсов
- Упрощение управления пользователями

## 🏗️ **Архитектура системы**

### **Компоненты:**
1. **`xray/generate_client.py`** - модифицирован для проверки лимитов
2. **`manage_user_limits.py`** - управление лимитами пользователей
3. **`test_hard_limits.py`** - тестирование системы ограничений

### **Логика проверки:**
```
Создание ключа → Проверка лимитов → Создание/Отклонение
     ↓
Проверка существующих ключей пользователя
     ↓
Проверка количества активных устройств
     ↓
Применение ограничений
```

## 🚀 **Использование**

### **1. Создание ключа с ограничениями (по умолчанию):**
```bash
python3 run_generate.py username
```

**Результат:**
- ✅ Если пользователь не имеет ключей - ключ создается
- ❌ Если пользователь уже имеет ключ - создание отклоняется

### **2. Создание ключа без ограничений:**
```python
from xray.generate_client import generate_vless_client

result = generate_vless_client(
    clients_dir="xray/clients",
    client_name="username",
    enforce_limits=False  # Отключаем ограничения
)
```

### **3. Управление лимитами:**
```bash
python3 manage_user_limits.py
```

**Доступные действия:**
- 📊 Анализ использования пользователями
- 🛡️ Применение лимитов (удаление лишних ключей)
- 🔑 Создание ключа для пользователя
- 🗑️ Удаление ключа пользователя
- 🔍 Показать всех пользователей

## 📊 **Мониторинг и анализ**

### **Анализ использования:**
```bash
python3 manage_user_limits.py

```

**Вывод включает:**
- Общую статистику пользователей и ключей
- Количество активных IP адресов
- Нарушения лимитов
- Детали по каждому пользователю

### **Применение лимитов:**
```bash
python3 manage_user_limits.py
# Выберите опцию 2: Применить лимиты
```

**Автоматические действия:**
- Удаление лишних ключей (оставляется только самый новый)
- Переименование удаленных файлов с префиксом `REMOVED_`
- Логирование всех действий

## 🧪 **Тестирование**

### **Запуск тестов:**
```bash
python3 test_hard_limits.py
```

**Тестируемые сценарии:**
1. **Ограничение пользователей** - проверка, что нельзя создать второй ключ
2. **Ограничение устройств** - анализ текущих подключений
3. **Обход ограничений** - проверка работы с отключенными лимитами

### **Очистка тестов:**
Тесты автоматически очищают созданных тестовых пользователей, переименовывая их файлы с префиксом `REMOVED_`.

### **Ручные действия:**

## 🔧 **Устранение неполадок**

### **Частые проблемы:**

#### **1. "Пользователь уже имеет ключ"**
**Решение:** Удалите существующий ключ перед созданием нового
```bash
python3 manage_user_limits.py
# Опция 4: Удалить ключ пользователя
```

#### **2. "Превышен лимит устройств"**
**Решение:** Проверьте активные подключения и отключите лишние устройства

#### **3. Ошибки при применении лимитов**
**Решение:** Проверьте права доступа к файлам клиентов
```bash
ls -la xray/clients/
chmod 644 xray/clients/*.json
```
