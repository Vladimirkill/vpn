# 🎭 Интегрированная маскировка VPN - Руководство

## 🚀 **Почему интегрированная маскировка лучше?**

### ❌ **Проблемы отдельных процессов:**
- Дополнительная нагрузка на систему
- Сложность управления множественными процессами
- Риск сбоев и зависаний
- Необходимость отдельного мониторинга
- Потребление дополнительных ресурсов

### ✅ **Преимущества интегрированной маскировки:**
- **Встроена в бота** - один процесс для всего
- **Автоматическое управление** - запуск/остановка с ботом
- **Асинхронные задачи** - эффективное использование ресурсов
- **Централизованный контроль** - управление через админ-панель
- **Минимальное потребление ресурсов** - только необходимые операции

## 📊 **Техники маскировки**

### **1. Reality Protocol Masking**
```json
{
  "serverNames": [
    "www.microsoft.com",    // Основной dest
    "www.apple.com",        // Альтернативный
    "discord.com",          // Для геймеров
    "www.github.com",       // Для разработчиков
    "www.youtube.com",      // Популярный сервис
    "fonts.googleapis.com", // CDN трафик
    "www.wikipedia.org",    // Образовательный
    "stackoverflow.com"     // Техническая поддержка
  ],
  "fingerprint": "chrome",  // Стабильный отпечаток
  "dest": "www.microsoft.com:443"  // Надежный сервер
}
```

### **2. Dynamic Dest Rotation**
```python
# Ротация каждые 6 часов:
Cycle: Microsoft → Apple → Discord → GitHub → Microsoft
```

### **3. Background Traffic Noise**
```python
# Минимальный фоновый трафик:
- DNS запросы к популярным доменам
- Случайные интервалы (5-30 минут)
- Имитация человеческого поведения
```

### **4. Geographic Routing**
```json
{
  "routing": {
    "rules": [
      {
        "domain": ["geosite:category-ads-all"],
        "outboundTag": "block"  // Блокировка рекламы
      },
      {
        "domain": ["geosite:cn", "geosite:ru"],
        "outboundTag": "direct"  // Локальный трафик
      }
    ]
  }
}
```

## 🚀 **Запуск и использование**


## 🛡️ **Безопасность и рекомендации**

### **Лучшие практики:**
1. **Мониторинг логов** - регулярно проверяйте на предмет обнаружения
2. **Ротация параметров** - не используйте одни настройки слишком долго
3. **Разнообразие доменов** - используйте разные serverNames для клиентов
4. **Обновления** - следите за новыми техниками маскировки

### **Признаки возможного обнаружения:**
- ❌ Частые разрывы соединений
- ❌ Медленная скорость подключения
- ❌ Ошибки в логах Xray
- ❌ Блокировка определенных сайтов

### **Действия при обнаружении:**
1. Немедленно сменить dest сервер
2. Обновить список serverNames
3. Изменить порт (если возможно)
4. Усилить фоновый трафик
5. Рассмотреть смену IP сервера

## 📞 **Поддержка и устранение неполадок**

### **Частые проблемы:**

#### **Маскировка не запускается:**
```bash
# Проверить логи бота
journalctl -u vpn-bot -n 50

# Проверить права доступа
ls -la /var/www/vpn/vpn_bot/utils/masking_manager.py
```

#### **Ротация не работает:**
```bash
# Проверить активные задачи
ps aux | grep python | grep vpn-bot

# Проверить логи ротации
journalctl -u vpn-bot | grep "rotation\|ротация"
```

#### **Xray не перезагружается:**
```bash
# Проверить права systemctl
sudo -u vpn-bot systemctl reload xray

# Проверить статус службы
systemctl status xray
```
