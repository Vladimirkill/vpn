# 🚀 Автоматический перезапуск Xray после создания клиента

## 🎯 **Описание**

Система автоматически перезапускает Xray после создания нового VLESS клиента, что обеспечивает:
- ✅ **Мгновенную активацию** новых ключей
- 🛡️ **Безопасность** пользователей (защита от утечки IP)
- 🔄 **Стабильность** сервиса
- 📱 **Автоматизацию** процесса

## 🔧 **Как это работает**

### **1. Процесс создания клиента:**
```bash
python3 run_generate.py client_name
```

### **2. Автоматические действия:**
1. **Создание клиента** - генерируется UUID и конфигурация
2. **Сборка конфига** - запускается `build_config.py`
3. **Проверка Xray** - проверяется статус сервиса
4. **Безопасный перезапуск** - используется `safe_restart.py`
5. **Fallback restart** - если безопасный не сработал
6. **Проверка работоспособности** - проверяется порт и статус

### **3. Типы перезапуска:**

#### **🛡️ Безопасный перезапуск (приоритетный):**
- Использует `safe_restart.py`
- Защищает IP пользователей от утечки
- Плавное завершение активных соединений
- Автоматическое восстановление

#### **🔄 Обычный перезапуск (fallback):**
- `systemctl restart xray`
- Используется при ошибках безопасного перезапуска
- Быстрый, но менее безопасный

## 🛠️ **Устранение неполадок**

### **Проблема: Xray не перезапускается**
```bash
# Проверка скрипта safe_restart.py
ls -la xray/safe_restart.py

# Проверка прав доступа
chmod +x xray/safe_restart.py

# Ручной перезапуск
systemctl restart xray
```

### **Проблема: Клиент не добавляется**
```bash
# Проверка прав доступа к директории
ls -la xray/clients/

# Проверка конфигурации
cat xray/final_config.json | grep "UUID_КЛИЕНТА"

# Перезапуск вручную
python3 xray/build_config.py
systemctl restart xray
```

### **Проблема: Порт 443 не слушает**
```bash
# Проверка статуса
systemctl status xray

# Проверка конфигурации
cat xray/final_config.json | grep "port"

# Перезапуск
systemctl restart xray
```
